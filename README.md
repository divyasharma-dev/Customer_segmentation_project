
# Customer Segmentation Project

## Overview
This project focuses on customer segmentation using demographic and purchasing behavior data. The objective is to identify different customer groups that can help businesses improve marketing strategies, customer retention, and sales performance.

The project is developed using Power BI for data cleaning, analysis, visualization, and customer clustering.

## Objectives

- Analyze customer purchasing behavior
- Identify high-value and low-value customers
- Segment customers based on demographics and buying patterns
- Build an interactive Power BI dashboard
- Generate business insights for targeted marketing

## Dataset

The dataset contains customer order information including:

- Customer ID
- Gender
- Age
- Age Group
- Order Date
- Sales Amount
- Quantity
- Product Category
- Sales Channel
- City
- State
- Country

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel 

## Dashboard Features

### Customer Overview
- Total Customers
- Total Revenue
- Average Order Value
- Total Orders

### Customer Demographics
- Customers by Gender
- Customers by Age Group
- Customers by State

### Purchase Analysis
- Revenue by Category
- Revenue by Sales Channel
- Monthly Sales Trend

### Customer Segmentation
Segments based on purchasing behavior:

- High Value Customers
- Regular Customers
- Occasional Buyers
- Low Value Customers

Segmentation factors:

- Total Spending
- Purchase Frequency
- Average Order Value

## Key Insights

- Highest revenue generating customer segment
- Most popular product categories
- Best performing sales channels
- Customer age distribution
- Geographic sales distribution
